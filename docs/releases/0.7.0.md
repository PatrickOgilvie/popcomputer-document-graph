# @popcomputer/document-graph 0.7.0

v0.7.0 adds PostgreSQL search coalescing. It also ships everything listed for
0.6.0, which was tagged but never published.

## Why

A matchmaker search on a production catalogue ran one retrieval for its
descriptive query and one per key phrase. Every retrieval issued its own
semantic, text and topology statements, so about 20 statements competed for
the four pooled connections a Cloudflare Worker request could hold.

When individual queries slowed, the queue stretched into seconds. Vector
searches that normally take 100 ms measured 2 to 8 s, and a queued query that
waited past the 5 s connection timeout failed the whole search.

## Added

- `coalesceSearches: { windowMilliseconds, maximumBatch }` on
  `postgresDocumentGraph`, off by default.
  - **Semantic searches** that share a scope, embedding profile and plan
    become one statement: a branch of CTEs per query vector, each shaped like
    the single-search statement, joined with `UNION ALL` and re-sorted per
    branch.
    - Exhaustive plans read the scope once for every vector.
    - Approximate plans run one index scan per vector, with `ef_search` sized
      for the batch's largest candidate count.
  - **Topology reads** for the same relation, direction and bound merge their
    document keys into one read, and each caller receives its own groups.
  - **Timing:** the first search waits up to `windowMilliseconds` (default
    2 ms) for others, and a batch of `maximumBatch` (default 16) flushes at
    once.
  - **Failure:** a batch runs under one statement timeout and fails together.

## Upgrade

No migration. Nothing changes until `coalesceSearches` is set. Build the
storage Layer per request on Cloudflare Workers, so a batch never spans
requests.

## Verification

- 274 unit tests, and 287 with the PostgreSQL and pgvector 0.8.1 suites.
- On pgvector with an HNSW index, six concurrent searches ran as one statement
  and matched each search run alone, chunk for chunk and score for score, on
  both the exhaustive float64 path and the index path.
