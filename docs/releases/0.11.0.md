# @popcomputer/document-graph 0.11.0

v0.11.0 runs on stable Effect 4. It requires `effect@^4.0.0` and is tested
against 4.0.2. Behavior, storage, and indexes are unchanged.

## Why

Effect 4 left release candidates. The previous `^4.0.0-rc.109` peer range
kept applications on prerelease builds and mixed poorly with packages that
already require the stable release.

## Changed

- The `effect` peer dependency is `^4.0.0`. Release candidates are no longer
  supported.
- `Sha256HexSchema`, the identity schemas built on it, and
  `TurbopufferNamespaceSchema` use `Schema.isBetweenLength`, the stable name of
  `Schema.isLengthBetween`. Validation and its messages are unchanged.
- Identifier, digest, and numeric-string patterns are Unicode regular
  expressions, so they still appear as `pattern` when you generate JSON Schema
  from them. Matching is unchanged.

## Upgrading

Install `effect@^4.0.0` and move every `@effect/*` package to the same
version. No schema migrations or reindexing are required.
