v0.4.1 fixes storage validation and simplifies Effect internals following a
one-off audit with `@popcomputer/lint`.

## Fixes

- PostgreSQL semantic and text candidate decoding rejects non-finite scores
  as invalid stored state before ranking.

## Maintenance

- Simplified yieldable errors, direct service provisioning, typed decoding,
  tagged schemas, and nullish defaults while preserving encoded data shapes.
- Replaced ad hoc persisted JSON parsing with typed Effects while preserving
  storage error handling.
- Made the retrieval concurrency regression deterministic and added coverage
  for non-finite scores and malformed persisted rows.
- Reduced findings from the one-off recommended lint preset from 3,881 to 998.
  The repository retains its existing lint configuration and dependencies.

## Upgrade

This is a patch release. Upgrading from 0.4.0 requires no schema migrations or
reindexing.

```sh
npm install @popcomputer/document-graph@0.4.1
```

## Verification

- 242 Bun tests passed; 13 live PostgreSQL/Turbopuffer integration tests were
  skipped because their environments were not configured.
- Existing lint, source and consumer type checks, Cloudflare Workers runtime,
  package build, and Node ESM smoke checks passed.
