# @popcomputer/document-graph 0.10.0

v0.10.0 lets Turbopuffer embed documents with one of its managed models. The
vectors reach indexing through the ordinary `EmbeddingProvider`, so stores,
publication and mirrors work as before.

## Why

Turbopuffer embeds a string attribute on write when its schema sets `embed`,
and returns the vector to queries. An application that already searches
Turbopuffer can drop a separate embedding service for documents. But
Turbopuffer has no endpoint that only embeds, and this package's indexes
expect vectors from the provider before they write.

## Added

- **`makeTurbopufferNativeEmbeddingProvider({ profile, model, client, embedQuery })`**
  - Writes each document to the client's namespace under its content hash,
    with `embed` set on the text, then reads the stored vector back with a
    strongly consistent query.
  - Reads content the namespace already holds for the same model instead of
    embedding it again, so retried indexing costs no tokens. Rows stored for
    another model are never reused.
  - A namespace that does not exist yet is treated as empty; the first write
    creates it. Turbopuffer rejects writes that name another model.
  - `batchSize` (default 256) bounds each write and read.
  - Transport failures are `EmbeddingProviderFailed` `unavailable`; a missing
    or wrongly sized vector is `invalid_response`.
- The opt-in live Turbopuffer suite embeds two documents with
  `TURBOPUFFER_EMBEDDING_MODEL`, by default `qwen/qwen3-embedding-0p6b`.

## Upgrading

Nothing changes unless you compose the new provider. Give it a namespace of
its own, never a projection index namespace.

Turbopuffer embeds queries only inside its own searches, so keep your current
provider for `embedQuery`. A managed model may be served at another precision
than the service that embedded your stored vectors. For
`qwen3-embedding-0.6b`, Turbopuffer's document vectors had a median cosine of
0.994 against Cloudflare Workers AI's. Measure before reusing an existing
embedding profile for new documents.
